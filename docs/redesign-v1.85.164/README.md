Cost's money axis now increases precision only when its converted quarter-step needs it. The original compiled source162 displayed five distinct values for a $0.0123 maximum as [$0.01,$0.01,$0.01,$0.00,$0.00]. It now displays [$0.012,$0.009,$0.006,$0.003,$0.00]. Very small ranges use compact scientific currency notation; zero and ordinary ranges keep their prior formatting. Currency conversion happens before selecting precision. Axis titles and accessible chart ranges use that same formatter; stored values, summaries, rankings and tooltips remain unchanged. Axis width expands only for the affected precise ranges.

The new fixture also exposed overlapping custom hourly date labels. The amount-only build reproduces that defect, with its failure bound to its own compiled index hash. Date labels now fit the actual rendered font/region: exact scope endpoints stay visible, intermediate labels appear when space permits, and crowded endpoints occupy two lines. A ResizeObserver handles changes in plot width and disconnects on unmount. No selected interval or data point is removed. The daily canonical Cost frame is byte-identical to source162, including its original date-label layout.
