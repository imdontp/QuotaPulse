# ภาพเปรียบเทียบ Dashboard ล่าสุด

[เปิดภาพเทียบทั้ง 8 หน้า](review.html) ภาพแอปมาจาก source `54b7155` และฐานข้อมูลจำลองที่แยกไว้สำหรับการทดสอบ ตัวเลข จำนวนรายการ และรูปกราฟจึงไม่ใช่ข้อมูลจริงของผู้ใช้และอาจต่างจาก concept

ภาพจับที่ viewport เท่าภาพอ้างอิง ภาษาอังกฤษ ธีมมืด DPR 1 และ reduced motion ด้วย headless Chrome ภาพจับซ้ำของทั้ง 8 หน้าเป็นไฟล์ตรงกันทุกไบต์ และภาพอ้างอิงมี hash ตรงกับ refs ใน blueprint โดยบันทึก build และผลตรวจไว้ใน `capture-verification.json`

เพื่อไม่เก็บภาพซ้ำ เจ็ดภาพใช้ไฟล์ที่เคยบันทึกหลังตรวจขนาด mode, PNG metadata และพิกเซลว่าตรงกับภาพที่จับใหม่ ส่วน Models เก็บภาพใหม่เพราะต่างจากภาพ checkpoint259 จำนวน 3 พิกเซล แม้ภาพจับซ้ำภายในรอบใหม่นี้ตรงกันทุกไบต์ รายละเอียด hash และ path อยู่ใน `images-verification.json` หน้าเปรียบเทียบผ่านการเปิด–ปิดทั้ง 8 หัวข้อด้วยคีย์บอร์ดและโหลดภาพท้องถิ่นครบ 16 ภาพตาม `gallery-verification.json`

ยังต้องตรวจความตรงด้านสี ภาพ ตัวอักษร ระยะ กราฟ interaction และ motion ในทุกหน้าตาม blueprint และ overrides ภาพชุดนี้ไม่ใช่การรับรองความเหมือน 99–100% หรือการทดสอบภาษาไทย ธีมสว่าง provider จริง และจอจริง รุ่น Windows review257 ยังไม่รวมการแก้ Models ที่ตามมา
