# Models comparison density

[Compare the concept and the before/after images](review.html). The application images use the same isolated synthetic database of 504 records, six projects and twelve model/provider pairs across seven days. They were captured at the concept viewport of 1672 × 941, DPR 1, English/dark, fixed clock and reduced motion. The concept image is the manifest-verified original. Different data and approved blueprint semantics mean that the images cannot be interpreted as a fidelity score.

Before the change, the comparison table's viewport ended at y=800 while the last row ended at y=854.7; the final rows therefore required scrolling. The custom-scope notice and chart-data disclosure occupied separate vertical rows. They now share the comparison heading, with wrapping when space is limited, and the desktop panel's bottom padding is reduced by six pixels. In the same fixture the last row ends at y=828 and the table viewport at y=829. All twelve 37px rows are visible while the panel height and row typography remain unchanged.

The disclosure still opens a focusable, scrollable data table, and the scope and incomplete-pricing notice remain visible. The browser test selects the last model with the keyboard and checks all 30 chart-data rows. Sixteen English/Thai, dark/light and width cases cover a custom range, source constraint and incomplete pricing together, checking non-overlap and keyboard scrolling; one fixture record is made unpriced for those cases after the screenshots. Forty additional currency/layout cases and both repeat-identical dense captures passed. The first keyboard probe checked scroll position immediately after pressing End and failed; waiting for the browser's actual scroll resolved the test timing, after which all sixteen cases passed.

The production web build and 380 web tests passed. Eight API-backed row-trend cases passed pagination, selected-model deep links and failure recovery, including a 1,265-model stress case. Four Models capture pairs passed without masks: three were byte-identical and the English/light pair differed by 33 pixels with a maximum channel delta of 2, within the existing tolerance.

Whole-dashboard visual fidelity remains unproven. Review211 predates this change. Real provider data, physical tray/display behavior, cross-schema migration, production performance and the previously intermittent Runtime Map issue remain open.
