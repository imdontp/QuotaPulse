# Overview quota precision

Some readers can publish fractional quota percentages. The previous Overview printed the unbounded numeric string at the full headline font size. With an isolated 83.123456789% reading, the headline measured 478.8 px across a 233.7 px globe interior and extended over adjacent content. `before-state.json` and the unmasked before screenshot retain the reproduction. A first probe using 12.3456789% instead selected a different higher-risk window, so it is not used as the failure reproduction.

The headline now scales down only when the raw value plus percent suffix is longer than five characters, with a 12 px minimum. It preserves every digit in the DOM text, with no rounding, clipping, or new value. The 83.123456789% fixture now measures 168.1 px and fits inside the globe; the displayed text and progress stroke remain `83.123456789` in both before and after. Normal integer screenshots from the same fixture remained byte-identical to checkpoint247. [View before and after](review.html).

Web build and 382 web tests passed. The Overview browser regression checks real local API fixture data in English/Thai and dark/light, with 0%, 100%, 125%, 83.123456789%, 99.99999999999999%, a very small fractional value and unavailable data. The fractional cases also check 390, 900, 1280 and 1586 px viewports for globe containment, caption overlap and page overflow. The quota text and progress assertions retain the unrounded values. All four integer fixture capture pairs were byte-identical to each other and to the retained [checkpoint247 captures](../redesign-v1.85.247/theme-captures.tar.gz), so the earlier image archive is reused after verifying all eight hashes. Captures are unmasked and use an isolated synthetic database; no customer data was accessed. The build retains the existing Vite large-chunk warning.

This repair covers the central headline, not every long value in other parts of the dashboard. It is not whole-page or 99–100% concept acceptance. Review243 predates this change.
