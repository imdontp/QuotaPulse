# Providers cards without quota readings

On wide screens, cards with no published quota were stretched to the 360 px height of adjacent cards with readings. They now keep their compact 156 px minimum height while preserving their owner, state, no-quota message, reader count and management link. If all cards have no readings, the grid no longer reserves the tall-card minimum. Cards that do have readings keep their existing layout; data, owner order and selection behavior are unchanged. The loading grid retains its reserved size. Below 1280 px the existing layout is unchanged.

[View the reference and before/after fixture captures](review.html). The two captures use an isolated synthetic SQLite fixture, English/dark, 1672×941, DPR 1, a fixed clock, reduced motion and headless Chrome. In the mixed fixture, the two no-quota cards change from 360 px to 156 px; the two populated cards remain 360 px, and the comparison and health panels remain at y=570.5–806.5. The unmasked full-frame difference has 246,338 changed pixels, bounding box x=283–1671, y=21–541; this includes differences outside the cards, so it is not evidence of a card-only pixel change. The reference has more provider accounts and different facts; these are not manufactured to match the image. This change does not constitute visual acceptance of the page or all eight pages.

`npm run build -w @quotapulse/web` passed, with the existing Vite chunk-size warning; `npm run test -w @quotapulse/web` passed 382 tests. The compiled Providers capture regression passed all four English/Thai and dark/light combinations with four repeat pairs, two byte-identical and the other two within the existing recorded tolerance without masks. It checks the synthetic mixed fixture's card and footer geometry, keyboard selection of an owner without readings, existing comparison selection, actual published windows, reader/diagnostics navigation, the all-no-readings case, unknown/expired/tiny values, and 390/900/1280 px horizontal overflow. The after manifest and region measurements record the exact test scope and production index hash. The output override lets this run retain earlier capture evidence rather than overwriting it.

These are fixture and headless-browser checks; no live provider, physical monitor, whole-page visual approval or production performance claim is made. Review236 predates this source change.
