# ภาพเปรียบเทียบ Dashboard จาก review243

[เปิดภาพเทียบทั้ง 8 หน้า](review.html) ภาพด้านขวาใช้แอป build เดียวกับ review243 และฐานข้อมูลจำลองที่แยกไว้สำหรับการทดสอบ ภาพตัวเลข จำนวนรายการ และกราฟจึงไม่ได้แสดงข้อมูลจริงของผู้ใช้ และไม่จำเป็นต้องตรงกับตัวเลขใน concept

ภาพจับที่ viewport ขนาดเดียวกับภาพอ้างอิง ภาษาอังกฤษ ธีมมืด DPR 1 และ reduced motion ด้วย headless Chrome แต่ละหน้าจับสองครั้งได้ไฟล์ตรงกันทั้ง 8 คู่ ไม่มี browser error หรือคำขอที่ชุดตรวจห้าม ทั้ง 8 ภาพอ้างอิงมี hash ตรงกับไฟล์ในโฟลเดอร์ refs ของ blueprint และไฟล์ web build ทั้ง 88 ไฟล์มี hash ตรงกับ ZIP review243 ตาม `web-bundle-verification.json` รายละเอียดการจับภาพและข้อจำกัดอยู่ใน `verification.json`

จุดที่ยังต้องตรวจและปรับเทียบจากภาพชุดนี้:

| หน้า | จุดที่ยังต่างหรือยังต้องประเมิน |
| --- | --- |
| Overview | ตรวจ artwork ของวงแหวน แสง เส้น Runtime Map และระยะตัวอักษรเทียบต้นฉบับ โดยคง scope ของ quota และเหตุการณ์ที่สังเกตได้ |
| Live | ตรวจสีและความหนาแน่นของตารางและกราฟ เทียบกับแหล่งข้อมูลจริงก่อนพิจารณาเพิ่มรายละเอียดใน summary; ภาพต้นฉบับมีสถานะ queue/failure/latency ที่ override ไม่อนุญาตให้สร้างเอง |
| Projects | ตรวจ typography, ไอคอน และระยะใน card กับรายละเอียดด้านขวา; จำนวนการ์ดและกราฟขึ้นกับ project และ usage ที่บันทึกจริง |
| Models | ตรวจ typography, ขนาดวงแหวนและการจัดวางกราฟ/ตาราง; คะแนนคุณภาพและความเร็วใน concept ต้องไม่ถูกสมมติขึ้น |
| Cost | ตรวจสี กราฟ และความหนาแน่นของตาราง; ส่วน forecast ที่ยังพิสูจน์ข้อมูลครบไม่ได้แสดง Unknown |
| History | ตรวจระยะตัวอักษรและการจัดวางตารางกับแถบรายละเอียด; prompt/response และสถานะที่ไม่มีแหล่งข้อมูลต้องไม่ถูกจำลอง |
| Alerts | ตรวจกราฟ เส้นขอบ สี และรายละเอียดการ์ด; เกณฑ์และการคาดการณ์ต้องอิงข้อมูลที่ระบบรองรับ |
| Providers | ตรวจการจัดวางเมื่อมีและไม่มี quota รวมทั้งสีและขนาดการ์ด; ไม่เพิ่มบัญชี แผนราคา หรือ service latency ที่ไม่มีข้อมูล |

รายการนี้เป็นจุดตั้งต้นสำหรับตรวจต่อ ไม่ใช่การปิด gap หรือให้คะแนนความเหมือน ภาพชุดนี้ไม่ยืนยันภาษาไทย ธีมสว่าง การโต้ตอบ motion การใช้ข้อมูลจาก provider จริง หรือการทำงานบนจอจริง ต้องใช้หลักฐานแยกสำหรับแต่ละกรณีและ override ใน blueprint ยังคงมีผล
