The old desktop grid placed the legend on top of the plot. Moving the legend upward clears the plotted area: its bottom is y=283.5px while the top of the maximum recorded marker is y=288.5px. The SVG bounding box and all 60 plotted marker boxes and values are identical before and after, including empty buckets. Other data, chart scale, navigation and interaction are unchanged.
