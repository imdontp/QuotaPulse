# Visual gate: idle preview and observed motion

The required `npm run test:visual` failed because the daemon-free preview has no recent runtime observation, but its older assertion expected the Overview orbit to run. `before.log` records the failed assertion with the preview's idle, visible, non-stale and non-reduced state. The current product behavior pauses the idle orbit; no production behavior was changed.

The preview check now verifies that the idle orbit remains paused when visible, offscreen and visible again, while still checking visibility transitions. To retain and extend active-motion coverage, the same `test:visual` command also runs the compiled-app local API/SSE regression against an isolated synthetic database. It checks that a recent observed event starts the orbit, moving it offscreen pauses it while the event is still recent, and returning it onscreen resumes it. The regression also covers reduced motion, expiry, stale or unavailable quota, actual observed edge motion, duplication, cancellation and unmount. The scheduler notifications are manually emitted in this fixture. Its unique temporary output directory preserves earlier evidence.

The complete `npm run test:visual` passed after these changes. `pilot-verification.json` reports 21 preview screenshots, English/Thai and dark/light at four widths, interaction and the other checks it actually performs; the three marker checks are not a comprehensive privacy audit. `runtime-verification.json` reports the compiled regression and the production index SHA-256, which matches the index from checkpoint240. The pilot runs Vite and headless Chrome; the compiled regression uses headless Chrome with software-rendering flags. Neither proves physical-GPU performance, native minimize behavior, live-provider behavior, or visual approval against all eight concept pages. The 21 pilot screenshots are generated under `screens/redesign-foundation` and are not committed here. Review236 predates the source changes after its build.
