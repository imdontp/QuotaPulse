# ภาพเปรียบเทียบ Dashboard จาก source ล่าสุด

[เปิดภาพเทียบทั้ง 8 หน้า](review.html) ภาพแอปใช้ source `6ef57f1` และฐานข้อมูลจำลองที่แยกไว้สำหรับการทดสอบ ตัวเลข จำนวนรายการ และรูปกราฟจึงไม่ใช่ข้อมูลจริงของผู้ใช้และไม่จำเป็นต้องตรงกับ concept

ภาพจับที่ viewport เท่าภาพอ้างอิง ภาษาอังกฤษ ธีมมืด DPR 1 และ reduced motion ด้วย headless Chrome ภาพจับซ้ำของทั้ง 8 หน้าเป็นไฟล์ตรงกันทุกไบต์ ไม่มี browser error หรือคำขอที่ชุดตรวจห้าม ทั้ง 8 ภาพอ้างอิงมี hash ตรงกับไฟล์ refs ของ blueprint และ web build ที่จับภาพมี hash ตาม `capture-verification.json`

เพื่อไม่เก็บภาพซ้ำโดยไม่จำเป็น Overview, Models และ History เก็บภาพใหม่ ส่วนอีก 5 ภาพใช้ PNG จาก checkpoint245 หลังตรวจว่าขนาด โหมด RGB, PNG metadata และพิกเซลทุกตำแหน่งตรงกับภาพที่จับใหม่ ไฟล์ PNG ของภาพเก่าและใหม่มี hash ต่างกัน จึงไม่ได้อ้างว่าไฟล์ตรงกันทุกไบต์ รายละเอียดอยู่ใน `images-verification.json` ตรวจการเปิดทั้ง 8 หัวข้อด้วยคีย์บอร์ดและการโหลดภาพท้องถิ่นครบทั้ง 16 ภาพแล้ว โดยมีผลใน `gallery-verification.json`

ยังต้องตรวจสี ภาพ ตัวอักษร ระยะ กราฟและการจัดวางในทุกหน้าเพิ่มเติม เทียบกับ blueprint และ overrides โดยเฉพาะกราฟ Live, การ์ด Projects/Providers และ History detail ซึ่งข้อมูลจริงมีจำนวนและชนิดต่างจาก concept ภาพชุดนี้ไม่ยืนยันความเหมือน 99–100%, ภาษาไทย ธีมสว่าง motion การใช้ข้อมูล provider จริง หรือการทำงานบนจอจริง Review249 predates การแก้ History และ source ด้าน transcript ที่ตามมา
